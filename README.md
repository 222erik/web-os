# SnackbarOS 🍫

A browser-based operating system built with vanilla HTML, CSS, and JavaScript.
## 🖥️ Live Demo

https://222erik.github.io/web-os/

## ✨ Features

### Desktop Environment
- **Draggable windows** — Move windows around by dragging their title bars
- **Window management** — Open, close, and focus windows with z-index stacking
- **Taskbar/Dock** — Bottom dock with app icons and running indicators
- **System clock** — Real-time clock in the top bar

### Built-in Applications

| App | Description |
|-----|-------------|
| **Notes** | Manage your notes |
| **Calculator** | Calculator with basic arithmetic operations |

### Notes App
- Create new notes
- Click any note in sidebar to view/edit

### Calculator App
- Basic arithmetic: `+`, `-`, `×`, `÷`
- Decimal support
- Clear button
